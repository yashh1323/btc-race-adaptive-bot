Regime-adaptive `cbBTC/USDC` trading bot implementing `agent-fun/bars-replay/v1`. Combines EMA(45)/EMA(180) trend-alignment, 60-minute slope confirmation, no-chase price bounds, a 10% equity drawdown circuit breaker, and consecutive stop-loss capping to avoid chop whipsaws while riding sustained directional trends.
